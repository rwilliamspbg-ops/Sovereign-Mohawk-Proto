# Root Cleanup Archive Index — July 2026

This directory preserves the July 2026 root-document cleanup batch (Pass 4 of the
relocation described in [../../ROOT_DOC_RELOCATION_PLAN.md](../../ROOT_DOC_RELOCATION_PLAN.md)).
These are historical status reports, phase/sprint completion summaries, test-execution
write-ups, and planning documents from prior work sessions — moved out of the repository
root to keep the active documentation surface small and current. Nothing was deleted;
full git history is preserved for every file via `git mv`.

A caution for readers: several of these files make completion/validation claims that
were later found to not hold up against the actual codebase (e.g. files claiming all
Lean proof gaps were closed, contradicted by sorries found in a later commit). Treat
this archive as a historical record of what was claimed at the time, not as current,
verified project status.
