## Gap 1 — Filtration & Conditional Expectation Lemmas (Mathlib.Probability.ConditionalExpectation)

**Goal:** Prove that the update history up to round `t` forms an increasing family
of sub-σ-algebras `ℱ_0 ⊆ ℱ_1 ⊆ … ⊆ ℱ`, and establish conditional-expectation
properties for stochastic gradients:
`𝔼[‖θ_{t+1} − θ*‖² | ℱ_t]`.

**Status today:** `Theorem6MeasureTheoreticConvergence.lean` is a *rational surrogate*
(no probability spaces, no σ-algebras, no conditional expectation). It states
descent-lemma arithmetic only.

**Deliverables:**

1. New module `proofs/LeanFormalization/Filtration.lean` (or extend
   `Theorem6MeasureTheoreticConvergence.lean`):
   - Define a `FederatedFiltration` indexed by `ℕ` (rounds) over a probability
     space `(Ω, ℱ, ℙ)`, reusing `MeasureTheory.Filtration ℕ ℱ`.
   - Prove monotonicity: `∀ t, ℱ_t ≤ ℱ_{t+1}` (comes free from the
     `Filtration` structure's `mono'`).
   - Prove each `ℱ_t ≤ ℱ` (comes free from `le'`).
   - Define `historySigmaAlgebra (t : ℕ) : MeasurableSpace Ω` generated by the
     finite prefix of gradient submissions, and show it is a sub-σ-algebra of ℱ.

2. New module `proofs/LeanFormalization/ConditionalExpectationGradient.lean`:
   - State `stochasticGradient` as a strongly-measurable map
     `g : Ω → E` (parameter space `E = Fin d → ℝ` or `EuclideanSpace`).
   - Prove `integrable (g · θ)` and `condExp (g · θ) ℱ_t` exists.
   - Lemma: `𝔼[g(θ_t, ξ_t) | ℱ_t] = ∇f(θ_t)` (unbiasedness) — stated as a
     hypothesis on the noise distribution, proved for the i.i.d. case via
     Mathlib's `condExp` linearity.

3. Update `FORMAL_TRACEABILITY_MATRIX.md` row 6 / 11 to reference the new
   theorems (`federated_filtration_monotone`, `gradient_condExp_exists`,
   `gradient_unbiased`).

**Mathlib modules to import:**
`Mathlib.Probability.Process.Filtration`, `Mathlib.MeasureTheory.Function.ConditionalExpectation.Basic`,
`Mathlib.MeasureTheory.MeasurableSpace.Basic`, `Mathlib.Probability.Kernel.Basic`.

**Effort:** 2–3 weeks. **Risk:** high — Mathlib's conditional-expectation API
requires integrability side-conditions that are easy to get wrong; expect
multiple CI iterations.

**Verification:** `lake build LeanFormalization` green; new theorems appear in
`lake env lean --run` trace; no `sorry`/`axiom`/`admit`.

## Gap 2 — Measurability of Stochastic Gradient Noise (ξ_t ∼ 𝒟_t)

**Goal:** Prove `g_t(θ_t, ξ_t)` is strongly measurable from `(Ω, ℱ, ℙ)` to
`ℝ^d`, bridging custom noise (client heterogeneity, adversarial dropouts)
into `Mathlib.MeasureTheory.Measurable`.

**Status today:** noise distributions are modeled as rational parameters
(`sigma2`, `drift`); no probability space, no measurability claim.

**Deliverables:**

1. New module `proofs/LeanFormalization/Measurability.lean`:
   - Define `NoiseDistribution` as a `ProbabilityMeasure Ω` (or `PMF` for the
     discrete case, mirroring `Theorem4ChernoffBounds.lean`'s use of `PMF.binomial`).
   - Define `stochasticGradientOperator : Θ → Ω → E` and prove
     `Measurable (stochasticGradientOperator θ)` for each fixed `θ` (currying +
     `Measurable.comp`).
   - Prove measurability of the map `(θ, ω) ↦ g(θ, ω)` jointly (for the
     SGD update `θ_{t+1} = θ_t − η g_t`), using `Measurable.prod` and
     `Measurable.fst`/`snd`.
   - Dropout/adversarial case: model dropout as a Bernoulli mask; prove the
     masked gradient is measurable as a composition of measurable maps.

2. Add a Go-side witness: `internal/federation/noise_test.go` (or extend
   existing) asserting the runtime gradient path produces finite, non-NaN
   gradients for adversarial dropout patterns — a runtime sanity check that
   mirrors the measurability claim (finite outputs ⇒ no undefined-measure
   edge cases).

**Mathlib modules:** `Mathlib.MeasureTheory.MeasurableSpace.Basic`,
`Mathlib.MeasureTheory.Function.StronglyMeasurable`, `Mathlib.Probability.Distributions.Basic`.

**Effort:** 1–2 weeks. **Risk:** medium — mostly boilerplate measurability
lemmas; the dropout mask is the only nontrivial part.

## Gap 3 — Supermartingale Convergence & Robbins–Siegmund

**Goal:** Instantiate Robbins–Siegmund (or Doob's martingale convergence) to
prove, under bounded variance + Lipschitz smoothness:
`𝔼[V_{t+1} | ℱ_t] ≤ (1 − a_t) V_t + b_t`,
with `V_t = ‖θ_t − θ*‖²`, `a_t` step-size-dependent, `b_t` capturing
gradient variance and Byzantine noise.

**Status today:** `martingale_descent_step` is a rational inequality with no
expectation operator, no filtration, no supermartingale. The descent lemma is a
hypothesis, not derived.

**Deliverables:**

1. New module `proofs/LeanFormalization/RobbinsSiegmund.lean`:
   - Import `Mathlib.Probability.Martingale.Convergence` and
     `Mathlib.Probability.Martingale.Basic`.
   - Define `V : ℕ → Ω → ℝ` (nonnegative adapted process) and prove it is a
     supermartingale w.r.t. `ℱ_t` under the descent-lemma hypothesis:
     `Supermartingale V ℱ ℙ` (Mathlib's `Supermartingale` predicate).
   - State Robbins–Siegmund as a theorem consuming:
     `(a_t), (b_t) : ℕ → ℝ` with `∑ a_t = ∞`, `∑ b_t < ∞`, and the
     inequality above. Conclude `V_t → 0` a.s. (or `V_t → V_∞` a.s. with
     `∑ a_t V_t < ∞`).
   - If Mathlib lacks a ready Robbins–Siegmund, prove the special case needed
     (bounded variance + summable step sizes) via Doob's convergence theorem +
     a telescoping argument, documented as a derived lemma, not an axiom.

2. Connect to Gap 1: `V` must be `ℱ_t`-adapted and integrable — reuse
   `gradient_condExp_exists`.

3. Concrete guard theorem: at the 100-client / 1000-round profile, with the
   async staleness window from Gap 4, the supermartingale bound holds with
   explicit `a_t`, `b_t` values (numeric, machine-checked via `norm_num`/
   `native_decide`).

**Effort:** 3–4 weeks. **Risk:** high — Robbins–Siegmund is not a single
Mathlib lemma; likely requires composing Doob convergence + Fatou + a custom
telescoping lemma. Budget for proof-engineering.

**Verification:** `lake build` green; theorem names exported; no `sorry`.

## Gap 4 — Refinement Bridge Soundness for Asynchronous Go Execution

**Goal:** Prove floating-point rounding and async network delays in Go do not
violate the martingale upper bounds. This is the gap most directly tied to the
recent async-consensus work (PR #275).

**Status today:** `Refinement/Convergence.lean` covers the *synchronous* case only
(envelope equality when Go's `Heterogeneity = Lean's zeta²`). No async
staleness, no floating-point, no delay model.

**Deliverables:**

1. New module `proofs/Refinement/AsyncConvergence.lean`:
   - Model async aggregation: a gradient submitted at round `r` may be
     incorporated in rounds `r … r + W` where `W = StalenessWindow`.
   - Define `staleWeight (age : ℕ) : ℚ` (age decay, e.g. `1/(1+age)` or
     a configured decay), and prove `0 ≤ staleWeight age ≤ 1`.
   - Prove the async envelope is bounded by the sync envelope plus a
     staleness term:
     `asyncEnvelope ≤ syncEnvelope + stalenessTerm(W, maxDelay)`.
   - Prove the staleness term is summable over rounds (needed for
     Robbins–Siegmund `∑ b_t < ∞`).

2. Floating-point bridge:
   - Define `Float64` rounding as a rational perturbation `|x̂ − x| ≤ ε_mach |x|`
     (machine epsilon `2⁻⁵²`).
   - Prove the Go `EnvelopeBound` (float64) is within `ε_fp` of the Lean
     rational envelope: `|EnvelopeBound_go − envelope_lean| ≤ ε_fp`.
   - Prove the refinement: if the Lean bound holds, the Go guard (with
     rounding) still implies convergence up to `ε_fp`.

3. Go-side property tests:
   - `internal/federation/async_refinement_test.go`: feed gradients with known
     ages into `flushAsync`, assert the resulting aggregate norm ≤ sync
     envelope + staleness term (within float tolerance).
   - Extend `test/convergence_test.go` with an async case.

4. Update `Refinement.lean` root import and `FORMAL_TRACEABILITY_MATRIX.md`
   with new theorem names (`async_envelope_bounded`, `stale_weight_in_unit`,
   `staleness_term_summable`, `fp_refinement`).

**Effort:** 2 weeks. **Risk:** medium — floating-point reasoning in Lean is
novel for this repo; may need to model floats as rationals with error bounds
rather than native `Float`.
